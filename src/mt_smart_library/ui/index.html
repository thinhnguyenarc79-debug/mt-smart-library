Các mục lỗi khi quét

Một ô tìm kiếm tìm đồng thời trong máy tính và các nguồn online đã tích hợp. Nguồn chưa có phương thức truy cập hợp lệ được ghi rõ giới hạn bên dưới.

Key không ghi vào settings.json hay log. Ảnh chỉ gửi khi bạn bấm xác nhận.

Token dùng để tải model được tác giả cho phép tải. Lấy token tại trang tài khoản Sketchfab .

Blender: —

FBX, OBJ, USDZ, PLY, BLEND (và GLB lỗi) được Blender chuyển sang DAE ở chế độ nền rồi chèn vào SketchUp. Blender 5.x không xuất được DAE — dùng 4.5 LTS (có thể dùng bản Portable).

Dữ liệu người dùng lưu riêng tại — không bị ảnh hưởng khi cập nhật plugin.

Ảnh sẽ được gửi tới (model ) để phân tích. Có thể phát sinh phí API.

Dán Sketchfab token để tải model

Chỉ cần làm 1 lần. → sao chép mục API Token → dán vào đây.

Cần Blender để chuyển đổi model này

Chỉ cần làm 1 lần. Sau khi có Blender, plugin tự chuyển đổi và chèn tiếp.

File SKP phiên bản mới hơn

Có thể thử nạp, một số dữ liệu có thể bị mất. Tốt nhất lưu lại file bằng SketchUp 2022 (Save As).
